下载安装包 v0.8.0 ↗查看版本说明与校验值

1. 安装到自己的电脑

下载上面的专用 ZIP 并解压到长期保留的目录。GitHub 自动生成的 “Source code” 为图册仓库；MCP 使用 xinye-vis-mcp-0.8.0.zip。

先安装 uv 和 R 4.6.x，确保终端能找到 uv 与 Rscript。Python 3.11 由 uv 准备。在解压后的 xinye-vis-mcp 目录执行：

macOS / Linux

bash install.sh --example BK13

Windows PowerShell

powershell -ExecutionPolicy Bypass -File .\install.ps1 --example BK13

首次安装会联网恢复 Python / R 依赖；成功后生成一张示例图与本机 MCP 配置。Windows / Linux 脚本尚未做独立系统验收。

2. 接入你的 Agent

安装完成后读取 config/mcp-client.json；WorkBuddy AI 也可用 config/workbuddy.mcp.json。配置由安装程序写入你电脑的实际路径。

  • WorkBuddy AI：在 MCP 服务器配置中合并 xinye-vis-mcp 服务，保留其他已有服务。
  • Codex：将 command、args 写入 config.toml 的 [mcp_servers.xinye-vis-mcp]，env 写入对应的 [mcp_servers.xinye-vis-mcp.env]。查看完整配置示例。
  • ZCode：在 MCP 设置的 mcp.servers.xinye-vis-mcp 中合并相同字段。

保存后重连 MCP，对 Agent 说：

用 xinye-vis-mcp 检查环境，列出绘图方法，并用 BK13 生成一张示例图。

3. 用自己的数据绘图

在图册点击“Agent复制提示词调用”，将数据路径替换为自己的文件。Agent 先读取方法说明并校验文件，再运行绘图。

数据与输出

支持 CSV、TSV、XLSX 和显式声明类型的 RDS；必需字段以每款方法说明为准。输出图像、输入副本、参数、依赖版本、来源和重运行代码。

工具读取已有分析结果，不执行差异分析、富集检验或降维推断。优先复用作者或教程代码，改编与独立实现分别标注。安装包示例为合成数据，原图与复现的来源说明保留在各案例中。
