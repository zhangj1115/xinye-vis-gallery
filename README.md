# xinye-vis-mcp · 文献原图索引

17款富集结果可视化样式，16款为教程引述的论文原图，对应13篇文献，m16为教程示例。

每款展示期刊、论文标题、首次发表和卷期时间，并链接至原文与教程。页面支持搜索、放大图片及独立查看MCP绘图示例。所有图片内嵌于index.html。

文献来源见references.json和references.tsv。原图并非MCP生成结果，图片版权归原权利人，出版和许可说明见各论文原文。

此仓库是图册展示网站，MCP服务在用户自己的本地环境运行。

左侧提供bulk转录组、单细胞转录组、空间转录组、蛋白组、代谢组五个站点分类。当前17个案例全部归入bulk转录组，其他分类暂为空。
