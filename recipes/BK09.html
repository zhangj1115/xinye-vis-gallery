## 1. 文献介绍



论文题目为 **Reconstituting human primitive streak formation through extra-embryonic cell coordination**，发表于 Cell（2026；DOI: `10.1016/j.cell.2026.05.045`）。论文关注人类原条（primitive streak）形成过程中，胚外细胞如何与胚胎干细胞（ESCs）协调，诱导原条样分化、细胞迁移和后续原肠运动相关状态。



作者建立了多种共培养和 disc-Gastruloid 模型，主要比较以下细胞或条件：


- 

ESCs 单独培养；




- 

ESCs 与羊膜样细胞（AMLCs）共培养；




- 

ESCs 与滋养层干细胞（TSCs）共培养；




- 

ESCs 与胚外中胚层干细胞（ExMSCs）共培养；




- 

加入或不加入 CHIR 等诱导条件；




- 

将共培养结果与人胚胎不同阶段的转录组和空间数据进行比较。





论文的主线是：胚外细胞并不是被动的支持细胞，而是能够通过细胞间信号和空间协调，帮助 ESCs 获得原条形成、原肠运动以及胚层分化相关的转录状态。

| 单细胞 RNA-seq | **GSA-Human: HRA008084** | ESC 与 AMLC、TSC、ExMSC 共培养，以及 disc-Gastruloid 和延长培养模型的单细胞转录组；Fig. 2 的单细胞分析主要依赖这部分数据 |

## 2. Fig. 2H 的含义



#### Fig. 2H 比较了什么



Fig. 2H 比较的是两个条件下的 **undifferentiated cells（未分化细胞）**：


- 

单独培养的 ESCs（ESCs only）；




- 

与 AMLCs 共培养的 ESCs（ESCs co-cultured with AMLCs）。





这不是 AMLCs 与 ESCs 的直接细胞类型比较，而是在尽量相同的“未分化 ESC”细胞群中，比较是否存在 AMLC 共培养信号。因此，图中观察到的差异主要用来回答：



AMLC 共培养是否已经改变了未分化 ESC 的转录准备状态？



从代码和图 2 的处理流程看，相关元数据包括实验条件（如 `orig.ident`）和细胞注释列（如 `celltype_version1`）。Fig. 2 的分析先整合不同样本，再选取 `Undifferentiated cells` 群体进行条件间比较；代码中可见的相关条件名称包括 `ESC_A`、`ESC_AC` 和 `CO_ESC_AME_A` 等。



#### 左侧火山图表示什么



Fig. 2H 左侧是单细胞差异表达结果：


- 

**横坐标：Percentage Difference**，通常可理解为两个群体中基因表达阳性细胞比例之差，即 `pct.1 - pct.2`；




- 

**纵坐标：Log2-Fold Change**，表示平均表达量的 log2 fold change；




- 

**点的大小：Percentage Difference**，用于同时强调表达阳性比例差异较大的基因；




- 

**红色：Up regulation**，在共培养 ESCs 中相对升高的基因；




- 

**蓝色：Down regulation**，在共培养 ESCs 中相对降低的基因；




- 

**灰色：其余基因**，包括没有被重点标注的差异基因或背景基因；




- 

**虚线**：用于标示表达比例差异和 fold change 的参考阈值。





原图中重点标出的上调基因包括 **TBXT、MIXL1、EOMES、NODAL、MSX1、WNT8A、GBX2** 等，这些基因与原条形成、WNT/NODAL 信号和早期胚层分化有关。下调基因包括 **HESX1、SIX3、BMP2、OTX2、FEZF1、SHISA2** 等，它们更多与神经分化、前脑发育或神经外胚层方向有关。



#### 右侧富集图表示什么



右侧是对上调和下调差异基因分别做功能富集后的结果。论文图注将其描述为上下调基因的 enriched pathways/GO terms，图中展示了排名靠前的代表性条目。条形长度对应 `-log(P value)`，颜色对应上调或下调方向。



原文中，上调方向主要富集于：


- 

Regionalization；




- 

Stem cell differentiation；




- 

Formation of primary germ layer；




- 

Canonical Wnt signaling pathway；




- 

Gastrulation。





下调方向主要富集于：


- 

Regulation of neuron differentiation；




- 

Forebrain development；




- 

Axonogenesis；




- 

ERK1 and ERK2 cascade；




- 

Cell-cell signaling by Wnt。





#### Fig. 2H 想说明的结果



Fig. 2H 支持的生物学结论是：**AMLC 共培养会在 ESC 仍被归类为“未分化细胞”时，提前启动原条形成和原肠运动相关的转录程序，同时压低神经/前脑方向的表达倾向。**



换句话说，AMLCs 可能通过共培养环境对 ESCs 进行“预模式化”（priming）：细胞尚未完全变成原条或中胚层细胞，但已经出现了 TBXT、MIXL1、EOMES、NODAL 等原条相关基因的上调。这种结果把细胞共培养、差异表达和通路富集三个层次连接起来：



```text
AMLC 共培养
    ↓
未分化 ESC 的基因表达改变
    ↓
原条/原肠运动程序增强，神经前脑程序减弱
    ↓
为后续细胞迁移、胚层分化和 disc-Gastruloid 形成提供转录基础
```



需要注意，Fig. 2H 是转录组层面的比较，能够说明表达程序和富集方向发生变化，但不能单独证明某个 AMLC 信号分子已经构成了完整的因果机制。因果关系需要结合论文中的 CHIR 干预、共培养实验、迁移实验、流式和免疫荧光结果共同判断。

## 4. 用户自己制作这类图时应该准备什么数据



#### 最推荐的输入：Seurat 对象 + 注释列



如果使用 Seurat，至少需要一个可正常读取的 `.rds` 文件，并满足以下条件：


- 

对象中存在 RNA assay；




- 

已完成基本质控、标准化和必要的降维/聚类；




- 

`meta.data` 中有一个明确的细胞注释列，例如 `celltype`、`celltype_version1` 或 `annotated_subgroup`；




- 

该列中至少包含要比较的两个亚群；




- 

两个亚群细胞数不能过少，并且应确认不是明显的 doublet 或低质量细胞；




- 

`ident.1` 和 `ident.2` 的方向要提前确定，因为它决定 log2FC 正负号和上下调颜色。





典型的准备方式是：



```r
obj <- readRDS("your_seurat_object.rds")

# 假设细胞注释列叫 celltype
Idents(obj) <- "celltype"

de <- FindMarkers(
  obj,
  ident.1 = "group_A",
  ident.2 = "group_B",
  assay = "RNA",
  slot = "data",
  logfc.threshold = 0,
  min.pct = 0.05,
  test.use = "wilcox"
)
```



#### 如果已经有差异表达结果表



不一定要从 RDS 重新计算。也可以直接准备一个 DEG 表。绘图脚本至少需要这些列：





| 列名 | 含义 |
| --- | --- |
| `gene` | 基因符号 |
| `avg_log2FC` | 两组之间的平均表达 log2 fold change |
| `pct.1` | `ident.1` 中表达该基因的细胞比例 |
| `pct.2` | `ident.2` 中表达该基因的细胞比例 |
| `pct_diff` | `pct.1 - pct.2` |
| `p_val` | 原始 P 值 |
| `p_val_adj` | 多重检验校正后的 P 值 |
| `sig` | 可选，Up/Down/NS 分类 |





如果没有 `pct_diff`，可以这样计算：



```r
de$pct_diff <- de$pct.1 - de$pct.2
```



如果用户使用 Scanpy、FindMarkers 的其他版本或其他差异分析软件，只要把列名转换成上述格式即可。



#### 功能富集需要什么



上下调基因应分开进行富集。建议至少准备：



```r
up_genes <- de %>%
  filter(p_val_adj < 0.05, avg_log2FC > 0.5, pct_diff > 0.1) %>%
  pull(gene)

down_genes <- de %>%
  filter(p_val_adj < 0.05, avg_log2FC < -0.5, pct_diff < -0.1) %>%
  pull(gene)
```



还需要确认：


- 

基因名是 gene symbol、Ensembl ID 还是 Entrez ID；




- 

使用的物种数据库，例如人使用 `org.Hs.eg.db`，小鼠使用 `org.Mm.eg.db`；




- 

背景基因（universe）是否设置为本次检测到的全部基因；




- 

是否排除 `RPL`、`RPS`、`MT-`、`MALAT1`、`NEAT1` 等可能主导富集结果的 housekeeping 基因；




- 

富集结果使用原始 `pvalue` 还是校正后的 `p.adjust` 作为条形长度。
